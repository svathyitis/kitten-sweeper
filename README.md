# kitten sweeper

A kitten-themed Minesweeper. Plain HTML, CSS and JavaScript, no build step, no dependencies. Open `index.html` to play.

- Three levels: chill (8x8), normal (9x12), chaos (10x14)
- First tap is always safe
- Tap a number to chord, long-press or use flag mode to flag (fish)
- Works on phones; best times saved on the device
